## ✨ About the Project
**The Book** is a website dedicated to introducing books, their authors, and their readers.  
It provides clear information about each story and its writer, helping visitors discover the world of reading 📖.

---

## 🚀 Features
- Responsive design for all devices 📱💻  
- Simple and user-friendly interface 🎨  
- Display of books with images and short descriptions 🖼️  
- Elegant introduction section ✍️  

---

## 🛠️ Built With
- HTML5  
- CSS3 (with Media Queries)  
- GitHub Pages 🌐  


---

## ⚡ Usage
1. Open the website via:  
   👉 [The Book](https://dakirimohamed.github.io/the-book)
